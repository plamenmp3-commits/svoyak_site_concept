# Свояк — демоверсия для GitHub Pages

В архиве уже готовый сайт. Загружать нужно содержимое этого архива в корень репозитория, включая папки assets, brand, fonts и images.

1. Создайте репозиторий на GitHub и загрузите содержимое архива (сами файлы, а не архив и не папку dist).
2. В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root). Сохраните настройки.
3. После публикации первый вариант будет доступен по адресу https://ИМЯ.github.io/РЕПОЗИТОРИЙ/, а второй — https://ИМЯ.github.io/РЕПОЗИТОРИЙ/variant-2.html.
4. Если это персональный репозиторий ИМЯ.github.io, адрес второго варианта: https://ИМЯ.github.io/variant-2.html.

Меню, фильтры, карточки и форма-пример работают в браузере. Форма — демонстрация: она не отправляет и не сохраняет данные. Туры, цены и даты являются примерами. Для настоящих заявок потребуется подключение сервиса или сервера.

Кадр за столом создан ИИ для концепции. Пейзажи предоставлены Unsplash (ссылки на авторов в подвале сайта). Фирменные изображения и логотип предоставлены заказчиком; шрифты Onest и Cormorant Garamond, лицензии прилагаются в папке fonts.
